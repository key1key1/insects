# 곤충 배틀 도감

초등 고학년(10~13세)을 위한 곤충 도감 + 대결 시뮬레이션 웹 서비스입니다.
9개 분류군, 28종의 곤충 표본과, 서식지·시간대·날씨가 랜덤으로 조합되는
환경 카드에 따라 유불리가 갈리는 턴제 대결을 담고 있어요.

## 파일 구조

```
index.html          아이들이 보는 실제 서비스 화면 (도감 + 대결)
admin.html          관리자 전용 편집 페이지 (사진/텍스트 수정, 곤충 추가)
data/insects.json   곤충 데이터 전부 (이름·특징·공격법·스탯·사진 경로)
images/             곤충 사진을 넣는 폴더 (기본은 비어 있음 → 없으면 그림 아이콘 표시)
```

## GitHub Pages로 배포하기

1. 이 폴더(`index.html`, `admin.html`, `data/`, `images/`)를 그대로
   GitHub 저장소 루트에 올립니다 (커밋 · 푸시).
2. 저장소의 **Settings → Pages**에서 배포 브랜치를 지정하면
   `https://내아이디.github.io/저장소이름/` 주소로 서비스가 열립니다.
3. `admin.html`은 링크로 따로 공유하지 않으면 아이들 눈에는 잘 띄지 않아요
   (다만 완전한 비공개 페이지는 아니니, 정말 숨기고 싶다면 별도 인증을 추가해야 해요).

> ⚠️ **로컬에서 더블클릭으로 열면?**
> 브라우저 보안 정책 때문에 `data/insects.json`을 못 불러올 수 있어요.
> 로컬 확인용으로는 터미널에서 `python3 -m http.server` 실행 후
> `http://localhost:8000` 으로 열어보세요. (GitHub Pages에 올리면 이 문제 없음)

## 곤충 정보 / 사진 수정하기 (관리자 페이지)

`admin.html`은 비밀번호로 잠겨 있고, GitHub에 직접 저장하거나 JSON만
다운로드하는 두 가지 방법을 모두 지원해요.

### 0. 비밀번호
기본 비밀번호는 `insect1234` 예요. 꼭 바꿔서 쓰세요:
1. 아무 페이지에서 브라우저 개발자 콘솔을 열고 아래를 실행합니다.
   ```js
   crypto.subtle.digest('SHA-256', new TextEncoder().encode('새비밀번호'))
     .then(b => console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,'0')).join('')))
   ```
2. 출력된 값을 `admin.html`의 `ADMIN_PASSWORD_HASH` 상수에 붙여넣습니다.
3. 이건 클라이언트 잠금이라 완전한 보안은 아니에요 — 소스를 볼 수 있는
   사람은 우회할 수 있어요. "아무나 실수로 들어오는 것"을 막는 정도로
   생각해주세요.

### 1. GitHub에 직접 저장하기 (추천)
1. GitHub에서 **Settings → Developer settings → Personal access tokens →
   Fine-grained tokens**로 이동해 새 토큰을 만듭니다. 이 저장소 하나만,
   **Contents: Read and write** 권한만 주고, 만료기간을 짧게 설정하세요.
2. `admin.html`의 "GitHub 연결" 칸에 저장소 소유자 · 이름 · 브랜치 · 토큰을
   입력하고 "연결 저장"을 누릅니다. (토큰은 이 브라우저에만 저장돼요)
3. 곤충을 고르거나 추가하고, 사진은 **URL 붙여넣기**(위키미디어 커먼즈 등
   저작권 없는 이미지 링크) 또는 **파일 업로드** 중 골라서 넣습니다.
4. **"이 내용 반영하기"** → **"☁️ GitHub에 저장"**을 누르면 사진 파일과
   `data/insects.json`이 그 저장소에 바로 커밋돼요. 1분 이내로 실제
   사이트에 반영됩니다.

### 2. 수동으로 반영하기 (토큰 없이)
GitHub 연결을 안 했다면 **"⬇️ JSON만 다운로드"**로 받은 `insects.json`
파일을 저장소의 `data/insects.json`에 직접 덮어쓰고 커밋 · 푸시하면
됩니다. 사진을 파일로 올린 경우, 해당 파일을 별도로 다운로드해 `images/`
폴더에 넣어주는 과정이 필요해요 — 웬만하면 **URL 붙여넣기 방식**을 쓰는
게 훨씬 간편해요.

## 기본 사진 출처

28종 모두에 위키미디어 커먼즈(Wikimedia Commons)의 CC0 또는 CC-BY(-SA)
라이선스 사진을 기본으로 연결해두었어요. 링크만 참조하는 방식이라
저장소에 이미지 파일이 실제로 들어있진 않아요. 사진을 바꾸고 싶으면
관리자 페이지에서 얼마든지 다른 URL로 교체하거나 직접 업로드하면 됩니다.
