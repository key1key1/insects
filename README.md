# 곤충 배틀 도감

초등 고학년(10~13세)을 위한 곤충 도감 + 대결 시뮬레이션 웹 서비스입니다.
28개 분류군(목) 체계 안에서 43종의 곤충 표본을 담았고, 서식지·시간대·
날씨가 랜덤으로 조합되는 환경 카드 + 공격/방어 동시 선택 + 크리티컬/회피
랜덤이 어우러진 턴제 대결을 즐길 수 있어요.

## 파일 구조

```
index.html            아이들이 보는 실제 서비스 화면 (도감 + 즐겨찾기 + 대결)
admin.html             곤충 데이터 편집 페이지 (기본정보 / 사진 / 배틀 데이터)
admin-settings.html    GitHub 연결 + 관리자 비밀번호 변경 전용 페이지
insects.json            곤충 데이터 전부 (이름·특징·공격법·스탯·기술·사진 경로)
admin-config.json      관리자 비밀번호 해시(SHA-256)만 담은 작은 설정 파일
images/                 곤충 사진을 직접 올릴 때 쓰는 폴더 (URL 참조 방식이면 안 써도 됨)
```

데이터 파일들(`insects.json`, `admin-config.json`)은 다른 HTML 파일들과
같은 위치(저장소 루트)에 있어요. `images/` 폴더만 따로 나뉘어 있어요.

## GitHub Pages로 배포하기

1. 이 폴더 전체를 그대로 GitHub 저장소 루트에 올립니다 (커밋 · 푸시).
2. 저장소의 **Settings → Pages**에서 배포 브랜치를 지정하면
   `https://내아이디.github.io/저장소이름/` 주소로 서비스가 열립니다.
3. `admin.html` / `admin-settings.html`은 링크로 따로 공유하지 않으면
   아이들 눈에는 잘 띄지 않아요 (완전한 비공개 페이지는 아니니, 정말
   숨기고 싶다면 별도 인증을 추가해야 해요).

> ⚠️ **로컬에서 더블클릭으로 열면?**
> 브라우저 보안 정책 때문에 `insects.json` 등을 못 불러올 수 있어요.
> 로컬 확인용으로는 터미널에서 `python3 -m http.server` 실행 후
> `http://localhost:8000`으로 열어보세요. (GitHub Pages에 올리면 문제 없음)

## 아이들이 쓰는 화면 (index.html)

- **📖 도감**: 사진 없이 목(order)별로 묶은 가벼운 텍스트 목록 — 태블릿에서도
  빠르게 뜨도록 사진 로딩을 상세보기(모달)에서만 하도록 설계했어요.
- **⭐ 즐겨찾기**: 곤충 옆 ☆ 버튼으로 "나만의 표본"에 담기(최대 10종),
  이 브라우저(기기)에만 저장돼요(`localStorage`). 대결에서도 즐겨찾기만
  골라 쓸 수 있어요.
- **⚔️ 대결**: 1인용(컴퓨터와) / 2인용(같은 기기, 패스앤플레이) 선택 →
  곤충 선택 → 환경 카드 뽑기 → 매 턴 공격/방어 기술을 동시에(상대 선택은
  안 보임) 고른 뒤 **"⚔️ 결과 공개하기!"** 버튼을 눌러야 결과가 나와요.
  크리티컬·회피 확률에 시간대(밤/낮 등) 일치 여부가 반영되고, 화면
  오른쪽 아래 **📖 규칙** 버튼으로 전체 규칙(환경 효과·명중 판정·언더독
  보정·기적의 생존·연속 공격 피로)을 언제든 팝업으로 볼 수 있어요.
- 왼쪽 위 제목을 누르면 언제든 도감 홈으로 돌아가요.

## 곤충 데이터 / 사진 수정하기 (admin.html)

`admin.html`은 비밀번호로 잠겨 있어요. 편집 화면은 세 박스로 나뉘어요:
**기본 정보**(이름·분류·서식지·시간대·특징), **사진**(URL 또는 파일),
**⚔️ 배틀 데이터**(능력치·공격 방법·기술 3개 + 기술마다 공격/방어 종류).

GitHub 연결과 비밀번호 변경은 `admin.html` 안에 없고, 우측 상단
**⚙️ 설정** 링크로 들어가는 `admin-settings.html`에서 관리해요.

### 기본 비밀번호
초기 비밀번호는 `insect1234`예요. **꼭 설정 페이지에서 바꿔주세요.**

### 1. GitHub에 직접 저장하기 (추천)
1. `admin-settings.html` → GitHub Settings → Developer settings →
   Personal access tokens → **Fine-grained tokens**에서 새 토큰 발급.
   이 저장소 하나만, **Contents: Read and write** 권한만, 만료기간은
   짧게 설정하세요.
2. 저장소 소유자 · 이름 · 브랜치 · 토큰을 입력하고 "연결 저장"
   (토큰은 이 브라우저에만 저장돼요).
3. `admin.html`로 돌아가 곤충을 고르거나 추가 → 사진은 URL 붙여넣기
   또는 파일 업로드 → **"이 내용 반영하기"** → **"☁️ GitHub에 저장"**.
   1분 이내로 실제 사이트에 반영돼요.

### 2. 수동으로 반영하기 (토큰 없이)
GitHub 연결을 안 했다면 **"⬇️ JSON만 다운로드"**로 받은 파일을 저장소
루트의 `insects.json`에 직접 덮어쓰고 커밋 · 푸시하면 됩니다. 사진은
**URL 붙여넣기 방식**을 쓰는 게 훨씬 간편해요 (파일 업로드는 GitHub
연결이 있어야 자동으로 올라가요).

### 비밀번호 바꾸기
`admin-settings.html`에서 새 비밀번호를 입력하면 (GitHub 연결이 되어
있어야 해요) 그 해시값이 저장소 루트의 `admin-config.json`에 저장돼요.
다음 접속부터 새 비밀번호로 로그인하면 됩니다.

이건 클라이언트 잠금이라 완전한 보안은 아니에요 — 소스를 볼 수 있는
사람은 우회할 수 있어요. "아무나 실수로 들어오는 것"을 막는 정도로
생각해주세요.

## 사진 출처 & 로딩 속도

기본 43종 모두 위키미디어 커먼즈(Wikimedia Commons)의 CC0 또는
CC-BY(-SA) 라이선스 사진 링크를 달아뒀어요. 원본 대신 위키미디어의
축소본 기능(`?width=300`)을 붙여서 로딩 용량을 크게 줄였습니다. 새
사진을 추가할 때도 URL 끝에 `?width=300`을 붙이는 걸 추천해요.

## 분류(목) 체계

국립생물자원관 · 한국곤충명집(2022) 기준으로 곤충강의 28개 목을 모두
선택할 수 있게 해뒀어요(`admin.html` 분류 드롭다운 참고). 다만 매미목은
분류학적으로 노린재목에 통합되어 더 이상 별도 목으로 쓰이지 않지만, 이
서비스에서는 아이들이 이해하기 쉽도록 **"매미노린재목"**이라는 이름으로
유지했어요.
